# Projeto 04 — PRF 2025 | Python

## Objetivo

Preparar e analisar os dados de acidentes da Polícia Rodoviária Federal
de 2025 utilizando Python e Pandas.

## Etapas desenvolvidas

- Importação e inspeção dos dados;
- Tratamento de valores nulos;
- Padronização de variáveis;
- Criação da variável-alvo `acidente_fatal`;
- Criação de indicadores de gravidade;
- Criação de variáveis de identificação analítica;
- Validação das transformações;
- Construção da base analítica;
- Construção da base modelável;
- Verificação de data leakage;
- Exportação das bases tratadas.

## Bases geradas

- `base_analitica_prf_2025.csv`
- `base_modelavel_prf_2025.csv`
- `dicionario_variaveis_modulo4.csv`

## Tecnologias

- Python
- Pandas
- NumPy
- Jupyter Notebook / Google Colab
- Power BI
