# Projeto — Atividades de Excel

## Sobre o projeto

Projeto de estudo desenvolvido durante a formação da Aponti, com o objetivo de praticar recursos de **Excel para tratamento, análise e visualização de dados** a partir de uma base em formato CSV.

As atividades exploram operações matemáticas, funções estatísticas e condicionais, busca de informações, construção de gráficos e criação de tabela dinâmica.

## Atividades realizadas

### 1. Operações com os dados

Foram realizadas atividades envolvendo:

* adição;
* subtração;
* multiplicação;
* divisão;
* travamento de células;
* identificação de valores máximos e mínimos;
* remoção de registros duplicados.

### 2. Funções de análise

Foram utilizadas funções para contagem, soma, média, estatística e busca de dados:

* `CONT`;
* `CONT.SE`;
* `CONT.SES`;
* `SOMA`;
* `SOMA.SE`;
* `SOMA.SES`;
* `MÉDIA`;
* `MÉDIA.SE`;
* `MODA`;
* `MEDIANA`;
* quartis;
* `PROCV`.

### 3. Visualização de dados

Foram construídos **5 gráficos**, utilizando diferentes possibilidades de representação dos dados disponíveis na base.

O objetivo foi praticar a transformação dos dados em informações visuais que facilitassem sua interpretação e comparação.

### 4. Tabela dinâmica

Como atividade complementar, foi construída uma **Tabela Dinâmica** para explorar e resumir os dados de forma interativa.

## Competências desenvolvidas

O projeto permitiu praticar:

* operações matemáticas em planilhas;
* referências e travamento de células;
* tratamento e limpeza de dados;
* funções condicionais;
* funções estatísticas;
* funções de busca;
* análise e sumarização de dados;
* criação de gráficos;
* tabelas dinâmicas;
* organização de informações para análise.
